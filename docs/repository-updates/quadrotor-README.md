# Planar Quadrotor Simulator

Shelved C++ learning project implementing 2D planar quadrotor dynamics.

## Implemented

- Six-state model: position, attitude, and their rates
- Two rotor-thrust inputs and equations of motion
- Eigen-based state representation
- Fixed-step fourth-order Runge–Kutta integration
- OpenGL / ImGui visualization

## Scope

Linearization, state-space A/B matrices, LQR control, sensor models, and Kalman filtering were planned but never implemented. Historical devlogs describe the original roadmap.

Development paused during study abroad in Tokyo and was not resumed. Upcoming work on Team RoSE's URC simulator provides a related team context; it is not an implemented feature of this repository.
